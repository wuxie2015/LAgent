# Sub-Agent 实现与回归验证

日期：2026-10-31（Asia/Tokyo）

## 实现结果

第一版同步只读委派已完成。主模型可在正常工具调用中自行选择 `delegate_task(goal, context, expected_output)`，程序不强制所有任务委派，也不增加专门的路由模型请求。

子任务在 spawn 独立进程中运行，仅接收子任务输入、独立系统提示词及根目录项目规则，不连接主记忆。提供受限项目文件读取与搜索，以及网页搜索；不提供 Shell、计划任务、文件写入和递归委派。主 Agent 负责交接必要用户约束及核验关键证据。

默认每请求最多2个子任务、每子任务最多5轮；主子执行共享18次模型调用，预留一次主 Agent 最终回答。主 Agent 仍有原来的8轮上限。子任务默认总超时120秒，超时执行 terminate / kill 并回收进程。受限、无效结果、崩溃等状态明确返回；不会自动重试。

返回 JSON 默认限制3000字符，区分 completed / partial / failed，包含证据、限制和独立记录引用。超长结果显式降为 partial，完整模型响应保留在 details_ref。记录包含父子标识，以0600权限保存在被忽略的 data/subagents 中，进行尽力脱敏；完整过程不进入主上下文。

自定义主记忆目录同样被文件工具禁止读取。文件工具使用解析路径边界检查及逐级 O_NOFOLLOW 打开方式，禁止符号链接逃逸，限制普通文本大小、返回行数、返回字符与搜索结果数量。工具限制不是操作系统沙箱，不保证过滤全部私人信息。主记忆清理命令不删除独立子任务记录。

## 验证结果

- 基线：实现前 `python3 -m unittest discover -s tests -q`，125项通过。
- 最终全量回归：同一命令，141项通过，耗时6.543秒，无跳过项。
- `python3 -m compileall -q src tests`：通过。
- `git diff --check`：通过。
- HTTP集成使用本机127.0.0.1临时端口模拟Ollama，无真实模型或外部搜索请求。初次沙箱运行无法绑定回环端口；允许本机测试端口后，集成与全量回归通过。
- 回归输出中的调度异常提示来自已有故障注入用例，不是测试失败。

新增子 Agent 测试覆盖：

1. 独立上下文、主历史不泄漏、主记忆不共写、事件及0600记录。
2. 简单任务直接回答，不强制启动子任务。
3. 同轮子任务串行执行、最多任务数、跨请求计数重置。
4. 输入、上下文、结果、轮次上限及格式校验。
5. 共享调用预算、未用配额退还、最终回答调用保留。
6. 超时、工具执行期间超时、进程终止回收及崩溃保守计费。
7. 无效结果、禁止Shell与递归调用，失败后主任务继续。
8. 证据缺失或仍有未完成事项时不得保持completed。
9. 越界、敏感路径、符号链接、二进制、自定义主记忆目录约束。
10. 允许读取src/domain/memory源码，区分源码与根目录运行时记忆。
11. 搜索结果数量上限及敏感内容尽力脱敏。
12. CLI开启与关闭委派、配置参数校验。
13. 实际OllamaClient HTTP传输穿过spawn子进程，验证项目规则、白名单及最终整合。
14. 相同任务开启和关闭委派的上下文、调用次数和耗时对比。

## 同任务对比测量

夹具：4000字符本地样本，固定模型响应，直接与委派模式给出相同的结论及sample.txt:1引用。以下为一次确定性测试观测，字符数不是Token数。

| 指标 | 直接处理 | 委派处理 |
| --- | ---: | ---: |
| 主 Agent 最后一次请求消息字符数（不含工具定义） | 2584 | 915 |
| 主 Agent 最后一次请求字符数（含工具定义） | 3005 | 1347 |
| 主 Agent 两轮累计字符数（含工具定义） | 3557 | 1910 |
| 主子模型总调用次数 | 2 | 4 |
| 请求墙钟耗时 | 0.003274秒 | 0.186196秒 |

该夹具中主 Agent 最后一次消息量减少约64.6%，计入工具定义后减少约55.2%；总调用增加，spawn也增加本机开销。以上不能外推为真实模型Token成本、延迟或答案质量收益。Token字段在此夹具中为模拟值，不用作真实Token结论；实际运行仅在供应商返回计数时记录。

可选复现（输出到自行指定的临时文件，不自动纳入Git）：

```sh
SUBAGENT_BENCHMARK_OUTPUT=/tmp/lin-agent-subagent-benchmark.json python3 -m unittest discover -s tests -p test_subagent.py -v
```

## 使用与边界

重启CLI后默认生效，配置见README与.env.example。`SUBAGENT_ENABLED=false`可关闭委派工具。完整过程按details_ref引用按段核验，请勿再次加载全部子上下文。

记忆维护保留原有独立预算，不计入主子执行的18次调用。超时或崩溃时保守计入全部预留调用，不把预算扣除数当作已确认远端请求数。终止本地进程不能保证远端供应商取消已经接收的请求。

本次未调用真实Ollama模型或Tavily服务；自主委派的语义选择依赖实际模型遵循工具说明与提示词的能力，机制测试不保证所有真实任务都会正确拆分。原设计中的并发、后续追问、续跑及受控子任务写入为后续扩展，不属于本版验收范围。
